# 10. 종합: 지금 만들 수 있는 구조와 남은 빈틈

## 실제로 얻은 결론

게임 피드백으로 확인된 이미지를 이용해 **후보 식별과 일부 경계 탐지를 개선하는 것**은 가능했다. 룬 crop에서 개체별 Adapter·Exemplar가 학습했고, 강화 창에서는 확인 뒤 예시 메모리 13/24→22/24, OmniParser 변화 박스 0/18→18/18 같은 변화가 있었다. 반면 실험별 입력·데이터·지표가 달라 이를 하나의 시스템 정확도로 합칠 수 없다. 통합 루프에서는 목표 선택이 좋아져도 부재 오탐과 파서 점수 순위가 남았다. 마지막의 촘촘한 겹침 기억은 순위가 7/48→15/48로 올라갔지만 실제 수용 정답 1/48에 그쳤다.

## 권장 시스템 역할

```text
전체 화면
  ├─ OpenCV/YOLO 등의 부모 창 후보 제안 ── 후보 수·상자 품질 검증
  ├─ 후보별 DINO 특징 + Exemplar/개체별 판별기 ── 목표 ID 점수
  ├─ 부모 안 OmniParser/계층 OpenCV/DINO 패치 헤드 ── 자식 후보·상태 단서
  └─ 시간 연속성 + 게임 행동 영수증 ── 정말 같은 대상인지 확인
       └─ 확인된 경우에만 상태별 메모리/Adapter/검출 헤드 갱신
            └─ 옛 상태·부재·새 상태 검증 게이트 → 채택 또는 보류
```

이것은 **현재 실험에서 도출한 설계**이지, 위 모든 경로가 하나의 배포 가능한 코드로 완성·검증됐다는 뜻이 아니다. 특히 첫 발견과 정체성, 요소 경계와 부모 ID, 후보 1위와 자동 행동 허용을 분리해야 한다.

## 현재 구조의 큰 빈틈

| 우선 | 빈틈 | 근거와 다음 확인 |
| --- | --- | --- |
| 높음 | **첫 변화 화면의 정체 확인** | 마스킹/파서 학습은 종종 게임이 11레벨 부모를 먼저 확인해야 한다. 안전한 보류·수동 확인·행동 영수증 대안을 마련한다. |
| 높음 | **부재 오탐·잘못된 자기학습** | 온라인 Exemplar 4/8, 세 학습기 통합 4/4 부재 오탐. 없는 창에서는 멈추고 무확인 고득점 후보를 학습하지 않는다. |
| 높음 | **후보 위치 의존** | 정체성 실험 다수가 이미 알려진 3슬롯. 위치·개수·크기·가림을 바꾼 전체 화면 시험이 필요하다. |
| 높음 | **부모·자식·시간의 동일성** | 변화 박스를 잘 찾아도 같은 창 Top-1은 최대 4/18. 역할별 ID와 조작 전후 연결을 독립 측정한다. |
| 중간 | **망각·오염·버전 관리** | OmniParser 한 장 갱신에서 옛 상태 6/6→4/6, YOLO 잘못된 갱신에서 24/24→0/24. 확인 출처·옛 상태 재생·회귀 게이트·복구 체크포인트가 필요하다. |
| 중간 | **작은 요소 경계와 점수 순위** | 재귀 DINO는 IoU≥0.5에서 개선됐으나 IoU≥0.75는 약했다. 통합 OmniParser는 맞는 후보가 있어도 최고점 선택 0/4. |
| 중간 | **새 게임 일반화·비용** | 같은 합성 렌더러의 소수 세션, 일부 중복·테스트 재사용. 미사용 게임/스킨·해상도·실제 애니메이션과 처리·학습 시간 측정이 필요하다. |

## 아직 실행하지 않은 설계

**공유 UI 도메인 Adapter**, **상태 그래프 기반 어댑터 선로딩**, 실제 자유 위치의 장기 시간 추적, 완전한 게임 UI DOM 생성, 안전한 무감독 첫 발견, 실제 게임 간 전이 성능은 이번 기록의 **제안**이지 측정 결과가 아니다. 개체별 Adapter와 OmniParser 일부 헤드는 실제 학습했지만, 이들 제안과 동일시하지 않는다.

## 다음 실험의 실행 순서

1. **새 봉인 세션을 먼저 생성:** 창 0·1·2·4개, 위치·크기·겹침·테마·배경·해상도를 바꾸고, 현재 문서 작성·튜닝에 사용한 시드는 제외한다. 실제 게임 캡처를 추가할 수 있으면 별도 도메인으로 둔다.
2. **부모 후보를 같은 전체 화면에서 평가:** OpenCV, 기본/학습 YOLO, DINO 경로의 후보 재현율·추가 상자·지연을 같은 후보 예산으로 보고, 창 없음도 넣는다.
3. **정체·상태·자식을 별도 채점:** 같은 부모 ID Top-1/거절, 자식별 IoU·선택 순위, 오답 클릭/보류 비용을 분리한다.
4. **확인 피드백 예산을 맞춰 갱신:** 0·1·3·8·N건 확인 뒤 Exemplar, 개체별 Adapter, 구조 헤드와 선택적 YOLO 갱신을 비교한다. 틀린 확인 신호를 주입해 오염 회복도 시험한다.
5. **세션 단위 쌍체 신뢰구간과 채택 게이트:** 미래 재탐지 개선뿐 아니라 부재 오탐·옛 상태·추론 및 추가 학습 지연을 함께 통과해야 채택한다. 실패하면 이전 모델로 복구한다.

채택 기준의 **숫자 임계값은 아직 게임의 오답 비용과 운영 예산이 정해지지 않아 결정하지 않았다**. 위 순서는 실험 계획이며 실행 결과로 가장하지 않는다.
