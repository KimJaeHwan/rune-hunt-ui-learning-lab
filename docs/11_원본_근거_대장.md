# 11. 원본 근거 대장과 공개 범위

이 대장은 숫자를 재검토할 때 찾아갈 **원본 작업 폴더의 파일명**을 남긴다. 경로의 기준은 로컬 `outputs/rune-hunt-lab/`이며, 아래에 적힌 파일이 전부 이 공개 저장소에 복제됐다는 뜻은 아니다. 공개 패키지는 [README](../README.md)의 마지막 구역 기억 코드·대표 결과와 이 번호별 감사 기록을 중심으로 한다. 대용량 화면 데이터, 모델 가중치·학습 체크포인트, 외부 원본 코드는 라이선스·용량·재현 환경 때문에 넣지 않았다.

## 공개 상태와 재현 한계

이 문서들은 과거 실험을 **감사 가능한 순서로 설명**하기 위한 것이지, 46개 스크립트와 모든 데이터·가중치를 새 PC에서 바로 재실행할 수 있는 완전 아카이브가 아니다. 현재 공개 저장소의 `experiments/`에는 마지막 DINO 지역 기억 경로의 일부 코드만 있다. 일부 과거 실행은 로컬 경로·별도 Python 환경·접근 승인된 DINOv3·OmniParser·YOLO 체크포인트가 필요하다. 특히 원본 TokenCut 재현 자료는 이전 요청에 따라 삭제됐다. 문서의 파일명은 출처를 식별하기 위해 보존하고, 원본 실행 재현이 확인된 것처럼 쓰지 않는다.
