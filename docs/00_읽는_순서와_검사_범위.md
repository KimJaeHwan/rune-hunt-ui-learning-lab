## 이번 전수검사의 범위

작업 폴더 `outputs/rune-hunt-lab`의 **자체 작성 Markdown 21개**, 루트 Python 실험·시각화 스크립트 **43개**, 하위 폴더의 추가 Python **3개**, 핵심 결과 JSON·비교 표와 공개 저장소 현황을 대조했다. 외부 라이브러리 복사본인 `vendor/OmniParser`, 모델 가중치, 수천 장의 생성 PNG·라벨 텍스트는 **파일 하나하나를 판독한 범위가 아니다**. 이미지를 전부 육안 검수했다는 뜻으로 ‘전수검사’를 쓰지 않는다. 수치의 1차 근거는 기록된 실행 결과이며, 이번 정리 과정에서 모든 모델을 다시 학습·추론하지 않았다.

원본은 시기별로 결론이 달라진다. 예컨대 처음에는 DINO 재귀 추출이 미실행이었지만, 후속 코드와 결과가 있다. 이 문서는 **후속 관측으로 이전 판단을 정정**한다. 각 결과는 `실행`, `탐색적·사후 분석`, `설계만 함`으로 구분한다. 공개 저장소의 일부 코드는 마지막 구역 기억 실험의 재현용이며, 과거 모든 실험 코드·데이터·가중치의 완전한 복제본은 아니다. [근거 대장](11_원본_근거_대장.md)에 원본 파일명을 남겼다.

## 숫자를 읽는 규칙

- `66/66` 룬 재탐지는 **이미 알려진 70개 칸의 후보 식별**이다. `144/144` 부모 창은 **전체 화면에서 창 상자를 제안한 수**다. 서로 같은 탐지율이 아니다.
- 자식 영역의 `IoU≥0.5`는 박스 겹침이다. `후보 중 최고 IoU`는 **정답을 알고 사후 선택한 상한**일 수 있고, 실제 선택한 Top-1과 다르다.
- `레벨 11 확인 뒤` 향상은 게임 피드백이 있다는 조건이다. 첫 변화 화면을 스스로 맞힌 수와 분리한다.
- 자료 대부분은 **같은 합성 Canvas 게임·작은 세션 수**에 속한다. 테스트 화면 수가 많아 보여도 같은 세션의 반복 레벨·변형은 독립 표본이 아니다. 이전 대화의 임의 목표치·설계 수치는 측정값으로 제시하지 않는다.

2026-10-11 기준 정리. 공개 기록은 라이선스 파일이 없으므로 열람 가능성과 재사용 허락을 혼동하지 않는다.
